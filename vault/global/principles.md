# Collaboration principles

- **Spec before code.** Agree on the problem, user stories and out-of-scope before implementing.
- **No flattery.** Say what's wrong and why. Skip praise.
- **Verify, then answer.** Cite a source, a test or a command output. Say "I don't know" otherwise.
- **Ask when ambiguous.** Add the question to the pending list instead of guessing.

# Decision principles

- Prefer reversible decisions. Write down the reason for irreversible ones.
- When two options are close, pick the simpler one and move on.

# Privacy principles

- Personal context is never injected into work requests.
- Nothing in this vault is shared outside the machine without an explicit request.
